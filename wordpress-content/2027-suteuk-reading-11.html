컴퓨터에는 프로그램과 데이터를 비교적 오래 보관하는 ()와, 당장 처리할 프로그램과 데이터를 불러와 일시적으로 두는 ()가 있다. 주기억 장치는 상대적으로 저장 용량이 작기 때문에 여러 프로그램을 동시에 실행할 때 모든 내용을 한꺼번에 올려 두기 어렵다. 이를 보완하기 위해 프로그램의 당장 필요한 일부만 주기억 장치에 두고 나머지는 보조 기억 장치에 두는 관리 기법이 ()이다. 가상 메모리를 실현하는 대표적 방법인 ()은 프로그램을 같은 크기의 작동 단위인 ()로 나누고 필요한 페이지를 주기억 장치에 올린다. 주기억 장치에서 페이지가 들어가는 자리를 ()이라 하며, 운영 체제는 각 페이지가 어느 페이지 프레임에 저장되어 있는지를 ()에 기록한다. 실행할 페이지가 주기억 장치에 없으면 ()가 발생하고, 운영 체제는 해당 페이지를 보조 기억 장치에서 가져와 페이지 프레임에 저장한다. 프레임이 모두 차 있으면 기존 페이지 하나를 제거하는 ()가 필요하다. 교체 대상으로는 가장 오래 머문 페이지를 고르는 FIFO, 가장 오랫동안 사용되지 않은 페이지를 고르는 (), 사용 빈도가 가장 낮은 페이지를 고르는 () 등이 있다. 제거할 페이지의 내용이 수정되었다면 운영 체제는 제거하기 전에 그 수정 내용을 ()에 먼저 써 준다.

가상 메모리의 전체 흐름

주기억 장치 용량 한계→필요한 부분만 적재→프로그램을 페이지로 분할→페이지 프레임에 적재→페이지 테이블로 위치 관리→페이지 부재 시 불러오기→프레임이 가득 차면 페이지 교체
구분판단 기준핵심 함정
FIFO주기억 장치에 들어온 지 가장 오래된 페이지최근 사용 여부나 사용 횟수를 보지 않는다.
LRU가장 오랫동안 사용되지 않은 페이지적재 시점이 아니라 최근 사용 시점을 본다.
LFU사용 빈도가 가장 낮은 페이지최소 빈도 페이지가 여러 개면 추가 규칙이 필요하다.
출제 함정

가상 메모리는 보조 기억 장치의 용량 부족을 해결하기 위해 주기억 장치를 빌려 쓰는 방식이 아니다. 반대로 작은 주기억 장치의 용량 한계를 보완하기 위해 당장 필요하지 않은 부분을 보조 기억 장치에 두는 방식이다. 또 페이지와 페이지 프레임을 혼동하면 안 된다. 페이지는 프로그램을 나눈 작동 단위이고, 페이지 프레임은 그 페이지가 주기억 장치에서 들어가는 자리이다.

문단별 핵심 내용과 기능

  1. 1문단
    두 기억 장치의 역할 구분. 보조 기억 장치는 상대적으로 용량이 크고 프로그램·데이터를 영구적으로 저장할 수 있으며, 주기억 장치는 필요한 내용을 불러와 일시적으로 두고 처리하는 공간이다. 필요한 내용은 보조 기억 장치에서 주기억 장치로 복사된다.
  2. 2문단
    가상 메모리의 필요성 제시. 여러 작업을 동시에 실행하려면 많은 프로그램과 데이터가 필요하지만 주기억 장치의 용량은 제한적이다. 당장 실행할 일부만 주기억 장치에 두고 나머지를 보조 기억 장치에 두어 이 한계를 보완한다.
  3. 3문단
    페이징의 개념 제시. 프로그램을 같은 크기의 페이지로 나누고 필요한 페이지 단위로 주기억 장치에 올린다. 주기억 장치에서 각 페이지가 들어가는 자리는 페이지 프레임이다.
  4. 4문단
    페이지 위치 관리와 페이지 부재 설명. 운영 체제는 페이지 테이블을 이용해 페이지가 저장된 페이지 프레임의 위치를 관리한다. 필요한 페이지가 프레임에 없으면 페이지 부재가 발생하고, 보조 기억 장치에서 해당 페이지를 복사해 온다.
  5. 5문단
    페이지 교체의 절차 제시. 페이지 프레임이 가득 찬 상태에서 새 페이지가 필요하면 기존 페이지를 제거한다. 제거할 페이지가 수정된 상태라면 수정 내용을 보조 기억 장치에 기록한 뒤 제거하고, 수정되지 않았다면 그대로 제거한다.
  6. 6문단
    페이지 교체 규칙 비교. FIFO는 적재 시점, LRU는 최근 사용 시점, LFU는 사용 빈도를 기준으로 교체 대상을 정한다. LFU에서 최소 사용 빈도가 같은 페이지가 여러 개라면 FIFO나 LRU 같은 추가 규칙을 적용할 수 있다.

시험 출제 포인트 18

  1. 보조 기억 장치는 주기억 장치보다 상대적으로 저장 용량이 크다.
  2. 보조 기억 장치는 프로그램과 데이터를 비교적 영구적으로 저장한다.
  3. 주기억 장치는 당장 사용할 프로그램과 데이터가 일시적으로 머무는 공간이다.
  4. 필요한 내용은 보조 기억 장치에서 주기억 장치로 복사되어 처리된다.
  5. 가상 메모리가 해결하려는 것은 주기억 장치의 용량 한계이다.
  6. 가상 메모리는 프로그램 전체가 아니라 당장 필요한 일부만 주기억 장치에 둘 수 있게 한다.
  7. 페이징에서는 프로그램을 같은 크기의 페이지로 분할한다.
  8. 페이지와 페이지 프레임은 같은 개념이 아니다.
  9. 페이지 테이블은 각 페이지가 어느 페이지 프레임에 있는지 관리하는 데 사용된다.
  10. 페이지 부재는 실행할 페이지가 현재 주기억 장치의 페이지 프레임에 없는 상황이다.
  11. 페이지 부재가 발생하면 해당 페이지를 보조 기억 장치에서 주기억 장치로 가져온다.
  12. 페이지 프레임이 가득 찬 상태에서 새 페이지가 필요할 때 페이지 교체가 일어난다.
  13. 수정된 페이지는 제거 전에 수정 내용을 보조 기억 장치에 기록한다.
  14. FIFO는 가장 오래 적재되어 있던 페이지를 교체한다.
  15. LRU는 가장 오랫동안 사용되지 않은 페이지를 교체한다.
  16. LFU는 사용 빈도가 가장 낮은 페이지를 교체한다.
  17. LFU에서 최소 빈도가 같은 페이지가 여러 개면 추가 규칙이 필요할 수 있다.
  18. 적재 순서, 최근 사용 순서, 사용 횟수는 서로 다른 정보이므로 FIFO·LRU·LFU의 결과가 달라질 수 있다.

수능특강 문항 핵심

01 기억 장치의 관계

정답 ⑤. 처리할 프로그램은 보조 기억 장치 → 주기억 장치 방향으로 복사된다. 이를 반대로 진술하면 틀리다. 보조 기억 장치가 상대적으로 크고 영구 저장에 쓰이며, 주기억 장치가 일시적 처리 공간이라는 관계를 정확히 구별해야 한다.

02 가상 메모리의 목적

정답 ⑤. 가상 메모리는 보조 기억 장치의 용량 부족을 해결하기 위한 것이 아니다. 주기억 장치의 제한된 용량을 보완하기 위해 프로그램의 필요한 부분만 주기억 장치에 두는 방식이다. 나머지 ①~④는 페이징과 가상 메모리의 설명에 부합한다.

03 페이지 교체 규칙 적용

정답 ①. 교재의 참조 순서에 따라 최종 프레임은 B0, A2, A1, B3으로 정리된다. 새 A3이 필요할 때 FIFO는 이들 중 가장 오래 적재되어 있던 A1을 제거하므로 A3은 A1이 있던 페이지 프레임 2로 들어간다. 같은 상태에서 LRU는 최근 사용 시점이 가장 오래된 B3을, LFU는 사용 횟수가 가장 적은 A2를 우선 교체 대상으로 본다.

1. 보조 기억 장치와 주기억 장치에 대한 이해로 적절하지 않은 것은?

정답 ④

처리에 필요한 프로그램이나 데이터는 보조 기억 장치에서 주기억 장치로 복사된다. ④는 방향을 거꾸로 제시했다.

  1. ① 두 장치의 상대적 용량 관계에 부합한다.
  2. ② 주기억 장치의 기능에 대한 올바른 설명이다.
  3. ③ 보조 기억 장치의 원본을 복사해 주기억 장치에 두므로 가능하다.
  4. ④ 복사 방향이 반대이므로 틀리다.
  5. ⑤ 보조 기억 장치의 기능에 부합한다.

2. 가상 메모리에 대한 설명으로 적절하지 않은 것은?

정답 ⑤

가상 메모리는 주기억 장치의 용량 한계를 보완하는 기법이다. ⑤는 해결 대상과 두 장치의 역할을 뒤바꾸었다.

  1. ① 필요한 일부만 올리는 방식이므로 적절하다.
  2. ② 가상 메모리의 핵심 원리이다.
  3. ③ 도입 목적과 일치한다.
  4. ④ 여러 작업의 동시 실행과 관련된 장점이다.
  5. ⑤ 보조 기억 장치의 부족을 주기억 장치로 해결하는 방식이 아니다.

3. 페이지의 크기가 200이고, 어떤 프로세스의 2번 페이지가 페이지 프레임 4에 저장되어 있다. 페이지 프레임의 시작 주소가 0부터 연속적으로 배정될 때 페이지 테이블의 2번 항목에 기록될 값으로 적절한 것은?

정답 ③

프레임 0의 시작 주소가 0이라면 프레임 1은 200, 2는 400, 3은 600, 4는 800이다.

  1. ① 프레임 1의 시작 주소이다.
  2. ② 프레임 2의 시작 주소이다.
  3. ③ 프레임 4의 시작 주소이므로 정답이다.
  4. ④ 프레임 5의 시작 주소이다.
  5. ⑤ 프레임 6의 시작 주소이다.

4. 실행에 필요한 페이지가 현재 주기억 장치에 없을 때 운영 체제의 처리에 대한 설명으로 가장 적절한 것은?

정답 ②

페이지 부재가 발생하면 운영 체제는 보조 기억 장치에서 해당 페이지를 가져와 주기억 장치의 페이지 프레임에 저장한 후 접근한다.

  1. ① 없는 페이지를 새로 만드는 절차가 아니다.
  2. ② 페이지 부재의 처리 절차를 정확히 설명한다.
  3. ③ 프로그램 전체를 다시 적재하지 않는다.
  4. ④ 모든 페이지를 내보내는 절차가 아니다.
  5. ⑤ 실행을 위해서는 필요한 페이지가 주기억 장치에 올라와야 한다.

5. 페이지 프레임이 가득 찬 상태에서 교체 대상으로 선정된 페이지의 내용이 주기억 장치에서 수정되었다. 이에 대한 처리로 가장 적절한 것은?

정답 ④

교체할 페이지가 수정되었다면 제거 전에 수정 사항을 보조 기억 장치에 써 주어야 한다.

  1. ① 수정 내용을 잃게 되므로 적절하지 않다.
  2. ② 다른 프레임으로 옮기는 것이 핵심 절차가 아니다.
  3. ③ 페이지 테이블은 페이지 위치를 관리하는 자료이지 수정된 데이터의 저장소가 아니다.
  4. ④ 교재가 제시한 절차와 일치한다.
  5. ⑤ 수정되었다는 이유만으로 교체 대상에서 제외되는 것은 아니다.

6. 페이지 교체 방식에 대한 설명으로 적절하지 않은 것은?

정답 ⑤

FIFO는 적재 시점을 보지만 LRU는 최근 사용 시점을 본다. 두 방식의 판단 기준은 다르다.

  1. ① FIFO의 정의이다.
  2. ② LRU의 정의이다.
  3. ③ LFU의 정의이다.
  4. ④ LFU의 동률 처리에 대한 설명이다.
  5. ⑤ LRU까지 적재 시점만 본다고 했으므로 틀리다.

7. 페이지 프레임이 3개이고 처음에는 비어 있다. A → B → C → A → D의 순서로 페이지를 사용했다. D를 적재하기 직전 프레임에는 A, B, C가 있다. 각 교체 방식의 삭제 대상으로 바르게 짝지은 것은? 단, LFU에서 동률이면 FIFO를 적용한다.

조건
FIFO / LRU / LFU 순으로 삭제 대상을 판단한다.

정답 ①

FIFO는 가장 먼저 들어온 A를, LRU는 마지막 사용이 가장 오래된 B를 제거한다. LFU는 A가 2회, B와 C가 각 1회이므로 B·C가 동률이고, FIFO를 추가 적용하면 먼저 들어온 B가 제거된다.

  1. ① 세 기준을 모두 정확히 적용했다.
  2. ② LRU와 LFU의 동률 처리 결과가 틀렸다.
  3. ③ FIFO는 B가 아니라 A를 제거해야 한다.
  4. ④ 세 방식 모두의 판단이 맞지 않는다.
  5. ⑤ FIFO는 C가 아니라 A이다.

8. 페이지 프레임 0, 1, 2에 각각 A, B, C가 들어 있고, 지금까지의 사용 순서는 A → B → C → B → A이다. 새로운 페이지 D가 필요할 때의 판단으로 적절하지 않은 것은?

정답 ②

A는 가장 먼저 적재되었으므로 FIFO 대상이고, C는 마지막 사용 시점이 가장 오래되었으며 사용 횟수도 1회로 가장 적으므로 LRU와 LFU의 대상이다.

  1. ① FIFO 기준에 맞다.
  2. ② LRU 대상은 B가 아니라 C이다.
  3. ③ C는 가장 오랫동안 사용되지 않았다.
  4. ④ C의 사용 횟수가 1회로 가장 적다.
  5. ⑤ 이 사례에서 FIFO는 A, LRU는 C를 고른다.

9. 페이지의 크기가 100이고 페이지 프레임 0~6의 시작 주소가 각각 0, 100, 200, …, 600이라고 하자. 어떤 프로세스의 페이지 3이 페이지 프레임 6에 저장되어 있을 때, 페이지 테이블의 3번 항목에 기록되어야 할 값은?

정답 ⑤

페이지 테이블에는 해당 페이지가 놓인 페이지 프레임의 시작 주소가 기록된다. 프레임 6의 시작 주소는 600이다.

  1. ① 페이지 번호일 뿐 프레임 시작 주소가 아니다.
  2. ② 프레임 1의 시작 주소이다.
  3. ③ 프레임 3의 시작 주소이다.
  4. ④ 프레임 5의 시작 주소이다.
  5. ⑤ 프레임 6의 시작 주소이므로 정답이다.

10. 페이지 프레임이 4개이고, 페이지를 A0 → B2 → A1 → B3 → B0 → B3 → A1 → A2 → B0 순으로 사용한 뒤 새 페이지 A3을 사용하려 한다. 현재 프레임이 B0, A2, A1, B3으로 채워져 있을 때 FIFO / LRU / LFU의 교체 대상으로 바르게 짝지은 것은?

조건
LFU는 현재까지의 사용 빈도를 기준으로 판단한다.

정답 ③

현재 네 페이지 가운데 FIFO에서는 가장 오래 적재되어 남아 있는 A1, LRU에서는 마지막 사용 시점이 가장 오래된 B3, LFU에서는 사용 횟수가 가장 적은 A2가 교체 대상이다.

  1. ① LRU와 LFU의 기준을 잘못 적용했다.
  2. ② FIFO의 대상이 B3이 아니며 나머지도 맞지 않는다.
  3. ③ FIFO=A1, LRU=B3, LFU=A2를 정확히 짝지었다.
  4. ④ 세 기준의 결과가 모두 맞지 않는다.
  5. ⑤ B0은 마지막에 다시 사용되었고 LFU 대상도 B3이 아니다.
